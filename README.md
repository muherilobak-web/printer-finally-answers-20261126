# The Printer Finally Answers

One line, in the voice of a tired office printer that finally answers
everyone staring at it: a flat, all-caps status log counting every page
it printed, every jam it survived, and every thank-you it never got —
then one quiet verdict.

## Run

```sh
node main.ts
```

Writes `entry.txt` — one line, no trailing newline — to `$OUTPUT_DIR`
(default `/output`).
